root_cause:
- FastAPI emits sync change created_at values as naive ISO datetimes such as 2026-07-10T01:20:38.507854.
- Go decoded created_at as time.Time, which only accepts RFC3339/RFC3339Nano with timezone, so /sync/changes unmarshalling failed with "server returned an unexpected response shape".

fix:
- Added client.APITime to parse RFC3339Nano plus FastAPI naive ISO datetime layouts at the HTTP DTO boundary.
- Updated engine test fixture for the APITime type.
- Added TestClientGetChanges_readsFastAPINaiveTimestamp.
- Completed CLI sync/status wiring left by the previous worker, preserving exit codes 1/2/3.
